# Kitronik example scripts

Unmodified example and test scripts for the Kitronik Air Quality Control HAT, one per
component (OLED, BME688, ZIP LEDs, RTC, buzzer, servo, …). They are copied from Kitronik's
repository, together with `kitronik-logo.jpg`:

https://github.com/KitronikLtd/Kitronik-Raspberry-Pi-Air-Quality-Control-HAT-Python
